## Review 发现与修正

- 初始化迁移失败：先准备数据库父目录和空文件，并统一迁移数据库路径。
- UI 只落实了部分外观：用户指出后移除大幅装饰，增大文字和触控区，补上设计全文、明确标准及对应回归。
- 刷新触发与旧数据：失效请求忽略迟到结果，重新加载时清理旧内容；App 页面重新聚焦会刷新。
- 退出时 API 失败：仍清理本地登录状态，避免过期会话无法退出。
- 图标入口引入过多字体：改为只导入使用的 Ionicons，减少 App 静态资产。
- 原浏览器下载未完成，测试启动失败：改用本机 Chrome 的独立测试上下文完成全部浏览器测试；不把此前失败写作通过。
- 测试框架依赖曾有 critical 告警：升级后最终审计无 critical；其余告警另见下文，不执行破坏兼容性的强制降级。
