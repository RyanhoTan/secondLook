# SecondLook UI 设计与验收规范

依据：同目录 apple-design-skill.md 保存了用户指定技能全文。以下是该技能在本产品中的具体落实，不以“用了圆角和模糊”作为完成标准。

## 产品感受

平静、清楚、可信，帮助用户阅读、比较依据与追踪变化。界面首先呈现搜索、对象和经历，不用大幅装饰或营销文案遮挡任务。Apple 风格指交互与细节原则，不是复制系统界面或品牌。

## 基础规范

- 系统字体；网页根字号 16px，正文以 rem 表达，主要正文约 15–16px，辅助文字通常不小于 12px。大标题单独设置字距和行高，中文正文保持舒适行距。
- 原生 Text 保持字体缩放，不关闭 allowFontScaling；文字变大时允许换行和容器增高。
- 浅色、深色、跟随系统三种外观；文字、背景、边界、标签全部用语义颜色。避免深色模式残留大面积浅色装饰。
- 普通正文对比度目标至少 4.5:1；大字至少 3:1；键盘焦点和控件边界清楚可辨。颜色必须配合文字表达状态。
- 主要点击区至少约 44×44 CSS px / 原生布局单位；图标不能只有视觉尺寸而没有点击热区。
- 控件按下立即给出反馈，动作在释放后触发；支持 disabled、busy、error、success，提交中防止重复触发。
- 用间距、字号与字重建立层级。只在需要区分独立任务时使用容器，不把所有信息都做成同等重量的卡片。
- 模糊用于导航、工具栏、浮层等功能层，内容应能从其下滚过；普通正文用稳定背景，不能多层浅色透明面叠加。

## 动作与过渡

- 普通列表、阅读页面不为了展示效果强加弹簧或手势。
- 可拖动/滑动的控件若加入，必须跟手、可中断，释放继承速度，并按预测终点吸附；不能用固定 CSS 动画伪装手势。
- 面板从触发源进入，沿原路径退出；过渡中允许用户改变决定。
- 仅在用户动量支持时加入适度回弹；普通菜单和按钮不做多余弹跳。
- 减少动态效果时去掉位移、弹性与视差，保留必要颜色和状态反馈；减少透明度时改用稳定实色；高对比模式强化边界。
- 主题切换避免整屏亮度动画或缓慢闪烁，不以动画拖延交互。

## 页面应用

| 页面/区域  | 具体设计                                                                     |
| ---------- | ---------------------------------------------------------------------------- |
| 发现       | 简短标题和说明，搜索在首屏；分类清晰；列表优先展示对象、问题、证据状态与时间 |
| 对象检索   | 独立名称/门店地址搜索，类别与城市组合；连续分隔列表突出名称、城市和地址；零记录用中性文字，公开经历数不表示对象质量 |
| 经历详情   | 正文阅读优先；发生日期与发布时间区分；后续变化明显且可追踪                   |
| 证据标签   | 灰/蓝/青/橙用语义变量管理；最小 12px；同时显示状态文字，不靠颜色判定         |
| 发布       | 分组表单、清楚标签、字段校验；匿名与亲历声明解释贴近控件                     |
| 审核       | 正文、决定与理由分组；明确通过代表发布规则检查，不代表事实核实               |
| 网页导航   | 桌面保留位置感；窄屏使用固定底部导航，为内容和安全区留空间                   |
| App        | 使用原生导航与滚动行为；保持触控热区、文字缩放和系统减弱动态效果支持         |
| 错误与空态 | 说清当前情况与下一步；网络/审核失败不能静默吞掉                              |

## 每次 UI 提交前的验收

- [ ] 桌面、390px 窄屏及文字放大后无横向溢出或内容遮挡。
- [ ] 深色、浅色、跟随系统均检查；切换后偏好正确保存。
- [ ] 正文、标签与次级文字可读；检查实际颜色对比度，而非只看截图。
- [ ] 常用点击区达到约 44px；按下反馈立即出现。
- [ ] 键盘可操作并有明显焦点；表单控件有名称和错误反馈。
- [ ] 减少动态效果、减少透明度和增强对比模式有对应实现。
- [ ] 导航状态、加载、错误、空态、成功和禁用状态齐全。
- [ ] 所有可见按钮能完成其说明的动作；未实现功能不伪装成可用。
- [ ] 浏览器回归测试与截图审查通过；原生端记录已验证和未验证环境。

## 当前修订背景

首版网页的辅助文字与标签过小，部分按钮热区不足，装饰性头图优先于任务。用户指出后，按本规范修订。修订是否完成以实际检查记录为准，本文不是检查通过证明。

## 当前设计：全量重设计 v2（2026-10-15）

用户明确要求弃用此前全部 UI。本版重新建立页面视觉和交互，已有业务接口继续使用。

- 网页导航：顶部品牌、胶囊导航、独立外观菜单、记录入口；移除原侧栏。
- 页面：居中阅读范围，搜索与分类为主要入口；移除原右侧说明栏与分散卡片布局。
- 记录：连续分组列表，细分隔线；对象、问题、摘要、作者、发生时间与后续入口各有层级。
- 颜色：黑白灰作为界面基础，颜色仅用于材料状态、错误及键盘焦点等必要反馈。
- 外观：可明确选择系统、浅色或深色，保存偏好；不再通过反复点击图标猜测当前状态。
- 材料：网页固定导航和手机底部浮层使用半透明材质；普通正文使用稳定底色。
- 切换：网页分类和导航使用 Motion 的共享布局弹簧，无回弹、可连续改变选择；不锁住输入。
- 浮层：阅读说明和外观选项从触发位置出现，关闭沿相同路径；支持关闭按钮/外部点击/Escape，关闭后合理恢复焦点。
- App：统一黑白灰语义颜色，重新制作搜索、分组记录、表单、外观分段选择与悬浮导航。
- 原生按压：先给出即时透明度反馈，缩放由临界阻尼附近的原生弹簧驱动；减少动态效果时保持静态反馈。
- App 的主题选择先更新界面，再持久化，避免让存储等待进入触控响应路径。

网页截图审查涵盖发现页、阅读详情、登录和发布；回归覆盖主题保存、文字对比度、390px 与 200% 字号、浮层及完整业务闭环。原生仍未完成真机交互测试，bundle 导出不能替代该项验收。

## 修订与历史阅读

- 详情正文前展示更正说明、版本号和公开时间；颜色保持克制，不用强警报暗示已经裁定事实反转。
- 历史按版本排列，网页使用原生折叠控件，App 使用已有按压反馈按钮展开；保留系统字体、主题和文字缩放。隐藏版本仅保留版本号、时间及处理提示。
- 修订表单说明哪些内容会公开；明确待审不覆盖当前公开版本。等待审核时显示提交内容，拒绝后展示理由并允许调整重提。
- 后台提供旧文对照，修改后的日期与公开更正说明独立显示；隐藏历史必须填写处理理由。
- 验证范围和截图见 progress.md 的原文修订记录；不得将网页截图或 bundle 导出视为原生真机验收。

## 图片材料与脱敏

- 来源说明紧邻图片；公开/仅审核使用明确文字，不靠颜色区分。原件访问范围与说明是否公开，在上传时说明。
- 图片保持原比例、随阅读列缩放；深浅色共用语义文字颜色，不改变图片内容。失败和重试提示明确，不使用模拟上传进度。
- 网页后台遮挡跟随指针 1:1 更新，使用 Pointer Capture，取消手势清除未完成选区；无固定动画或输入锁。支持百分比数字输入和逐个移除遮挡，作为键盘替代路径。
- 展示遮挡效果并检查来源说明后，审核人员明确确认隐私检查。服务器将遮挡写入副本，不以 CSS 黑块冒充安全脱敏。
- 材料管理、审核与公开详情均检查 390px、200% 字号；原生沿用已有按压反馈与主题控件。真机照片选择和图片加载仍须单独验收。

## 材料与正文版本

- 公开图片标注“对应第 N 版”；旧版图片随历史正文展开，避免与当前陈述混淆。
- 作者管理页区分上传所属版本和当前审核版本，正文更正后明确显示“新版待复核”；历史数据不明时如实说明。
- 后台展示当前待核正文、日期和版本，正文审核后刷新材料队列；过期决定提示刷新重试。
- 沿用现有表单、主题、折叠与按压反馈，不为版本切换增加装饰动画。网页浏览器验证不替代原生设备验收。

## 投稿结果确认

- 提交中立即显示状态并禁止重复触发；结果不明确时展示本次内容及“重试并确认结果”，解释下一步，不向用户展示请求标识或摘要等技术细节。
- 确认前不将修改后的内容混入原请求；成功后引导查看当前审核状态。明确的字段/权限错误返回原表单并保留输入。
- 网页确认标题接收键盘焦点，状态变化可被辅助技术读取；沿用语义主题与静态反馈，验证 390px 和 200% 字号的长文换行。
- 当前已支持从账号草稿恢复内容和投稿结果；未保存的离线输入仍须保持页面，不能以服务器草稿替代离线持久化保证。

## 草稿保存与恢复

- 将“有修改尚未保存 / 正在保存 / 草稿已保存 / 保存失败”放在编辑区前，失败有重试动作，未确认前不显示已保存；存储等待不阻塞输入。
- 保存与提交分开：未完整填写也可保存草稿，亲历声明和公开字段仍在提交时校验。“我的草稿”区分未提交与已提交结果，并允许继续或核对，不伪装成公开帖子。
- 对象新建界面与正文切换保留已输入内容；恢复时带回匿名选择和对象。并发冲突不覆盖本地文字，先说明后提供“替换输入并读取最新草稿”。
- 沿用系统字体、语义色、44px 触控区与静态状态反馈；长列表分页，390px 和 200% 字号检查。App 重启及辅助功能须记录实际设备结果。

## 浏览筛选

- 搜索与城市仍在首屏；问题类型、日期和排序收在“更多筛选与排序”内，按需展开，保留可访问标签、键盘焦点与减少动态效果支持。采用现有字段材质和语义色，不增加装饰动画。
- “发生日期”与“发布时间”分开表述，应用后在结果区域说明范围与排序；仅统计公开经历并说明样本含义。非法范围明确提示，保留上一次有效结果和 URL。
- 应用条件回到第一页，清除同时清空日期、城市、类别与关键词；网页刷新和历史导航恢复已应用值，不使用隐藏的本地偏好改写分享条件。
- 展开后的日期、排序和按钮检查 44px 热区、键盘焦点、实际对比度、390px 和 200% 字号；原生使用现有按压与分段控件，设备验证另记。

## 问题类型

- 发布/修订按对象类别展示复选框，组名明确“可多选”，说明至少一项、仅作分类；无对象时引导先选对象。每个标签连同文字具备至少 44px 高热区，选中有勾选标记，不只依赖颜色；普通标签沿用中性语义色。
- 草稿和投稿结果确认保留分类；仅修改分类也明确提交审核。详情与版本历史显示各自分类，旧记录用“问题类型未填写”，不伪造作者意见；后台提供新旧分类对照。
- 筛选支持全部问题类型，并在结果区域显示已应用类型与样本说明；网页 URL 恢复类型选择。表单键盘、深浅色实际对比度、390px、200% 字号和按压反馈按同一验收清单检查，真机另记。

## 发布前预览

- 将预览放在正文阅读区，完整展示对象与门店、日期、类型、正文和对外身份；不截断长文，也不以“使用昵称”替代实际将公开的昵称。匿名预览区域不显示账户昵称。
- 编辑区按钮为“预览发布内容”，预览区提供“返回修改”和“提交审核”。预览不是投稿成功，仍说明先审后公开；草稿保存状态保持真实，不把预览说成已持久化。
- 不增加二次确认弹窗或装饰动画；保留主题、系统字体、长文换行、44px 热区和即时反馈。网页预览标题可聚焦，返回恢复编辑焦点；App 预览从内容顶部开始并收起键盘，实际设备另记验证。

## 发生时间精度

- 以“具体日期 / 月份 / 大致时间范围”明确选择填写精度；只在范围模式展示结束日。切回具体日期时不把月份自动改成一号，其他内容保留。
- 预览、记录卡片、详情、历史、审核对照和材料审核都保留月份或“大致时间”文字标记，颜色不承载精度含义。长范围允许换行，不能以截断隐藏范围端点。
- 筛选区说明范围相交即展示；发生时间排序按范围起点，不能暗示确切发生先后。控件继续使用语义色、44px 热区、键盘焦点和系统字号，检查 390px、200% 字号及深浅外观；原生设备另记。

## 对象关注

- 对象名称和门店地址之后提供独立关注入口，明确只关注当前对象；没有公开经历也可关注。游客先登录，提交中禁用重复操作，失败保留原关注状态并允许重试，成功后读取服务器状态。
- 取消后说明仍关注该对象中的帖子时会继续收到该帖更新，避免用户把不同订阅混淆。通知展示对象名称，同一事件不因双重关注重复出现。
- 沿用现有按压、焦点、主题和系统字号；标题含长数字/英文时允许换行。检查 390px、200% 字号和减少动态效果，不以缩小文字或截断按钮隐藏问题。App 原生触控、返回后刷新与读屏仍待设备验收。

## 我的关注

- 帖子与对象独立切换、分页，列表使用间距和分隔线；对象名称、城市、门店地址帮助区分同名对象，不重复展示相同标题。
- 取消为明确按钮，处理中阻止重复操作；失败保留原列表，成功读取服务器结果。移除最后一页唯一记录后返回上一页，不留下误导的空白末页。
- 受限帖子显示“此记录暂不可查看”，只保留取消入口；响应与界面都不携带旧标题或对象信息。加载/失败不继续展示上一类型的旧数据。保留主题、系统字号、44px 热区和焦点，原生与网页分别记录验证范围。

## 文字审核长列表

- 将标题/正文/对象搜索与类型切换放在文字队列上方，标签带当前搜索范围的数量，较早提交优先。用文字说明审核通过的含义，避免把发布审核表现为事实认证。
- 搜索和切换类型回第一页，翻页与浏览器历史保留条件；加载时不展示旧条件的内容，失败有重试，无效条件能清除。审核末页唯一记录后回前页，切换条件后迟到的审核完成不得改变用户当前筛选。
- 图片审核区域保持独立，切换文字条件不丢失其遮挡编辑；文字审核通过后更新相关材料待审状态。沿用主题、键盘焦点和即时按压，检查 390px、200% 字号、44px 热区与减少动态效果，长正文与按钮不能靠截断隐藏。

## 材料审核长列表

- 以来源/正文/对象关键词、待审状态和公开范围筛选图片；“首次待审／新版待复核”“申请公开／仅供审核”用完整文字表达。按上传时间排列，数量只代表当前可审核范围，不是证据可信度。
- 文字和材料独立保留筛选与页码，改变一组不清空另一组；普通文字筛选不能丢失材料遮挡和审核说明。材料自身换页或换条件展示新列表，版本更新后仍要求按新正文核对，不沿用旧版遮挡决定。
- 末页唯一项处理后回前页，延迟的审核响应不覆盖后来选择的条件。加载、失败重试、非法条件清除、空态和页码完整；保留系统字体、主题、44px 热区、键盘路径、390px/200% 字号和减少动态效果。

## 通知长列表

- 通知可翻页查看旧进展；日期包含年份，不用模糊的旧日期混淆跨年记录。“查看最新进展”回到第一页，标为已读保留当前页与排序。
- 已读通过状态文字和按钮变化说明，文字仍可读。标记失败保持未读，不吞掉错误；加载失败有明确重试入口，非法分页可清除，空页可回前页或查看最新。
